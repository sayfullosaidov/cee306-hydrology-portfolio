# cee306-hydrology-portfolio

This repository contains my work for CEE 306: Hydrology – Water and Climate (Princeton University).  
It includes homework assignments, coding exercises, and projects related to hydrological modeling, streamflow and precipitation analysis, and data visualization using Python (pandas, matplotlib).  

The repository is organized by assignment, with separate folders for each homework or project. It serves both as a portfolio of my work in hydrology and as a reference for future projects in water resources and environmental engineering.
