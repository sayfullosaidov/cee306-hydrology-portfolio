# CEE 306: Hydrology — Water and Climate

**Princeton University | Spring 2026**

This repository contains selected computational work completed as part of **CEE 306: Hydrology — Water and Climate** at Princeton University.

The coursework explores fundamental hydrologic processes and their representation through mathematical models, numerical simulations, and data analysis using Python. Topics include watershed hydrology, precipitation, streamflow, evapotranspiration, groundwater, snow processes, and hydrologic forecasting.

The notebooks demonstrate the application of hydrologic concepts to real-world data, with an emphasis on understanding physical processes, implementing computational models, and interpreting simulation results.

## Repository Structure

The repository is organized into two main components:

| Directory | Description |
|---|---|
| `homework/` | Python notebooks exploring hydrologic concepts, physical processes, and numerical modeling techniques. |
| `forecasts/` | Hydrologic forecasting exercises applying statistical, conceptual, and data-driven approaches. |

## Topics Covered

- **Watershed Hydrology:** Water balance, storage, and runoff generation.
- **Rainfall–Runoff Modeling:** Linear reservoir models and streamflow response.
- **Evapotranspiration:** Energy balance and atmospheric controls on water fluxes.
- **Groundwater Hydrology:** Subsurface flow and groundwater dynamics.
- **Snow Hydrology:** Snow accumulation, snowmelt, and runoff.
- **Hydrologic Forecasting:** Model development, prediction, and performance evaluation.
- **Data Analysis:** Processing, visualization, and interpretation of hydrometeorological observations.

## Tools and Methods

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** NumPy, Pandas, Matplotlib, SciPy, and other scientific computing packages
- **Methods:** Water balance analysis, numerical simulation, conceptual hydrologic modeling, statistical analysis, and forecasting
