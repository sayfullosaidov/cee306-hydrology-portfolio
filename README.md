# CEE 306 — Hydrology

This repository contains a collection of Jupyter notebooks and computational work completed as part of my coursework in **CEE 306: Hydrology at Princeton University**.

The repository is intended to document the analyses, models, and programming exercises I worked on throughout the course. The notebooks reflect my application of hydrologic concepts using Python, including the analysis and modeling of different components of the hydrologic cycle.

## Topics Covered

The coursework explored a range of topics in hydrology and water resources, including:

- Watersheds and hydrologic systems
- Python for hydrologic analysis
- Hydrologic forecasting and forecast evaluation
- Linear reservoir models
- Hydrographs and stream gaging
- Precipitation
- Evapotranspiration
- Energy balance
- Groundwater
- Surface water and runoff processes
- Snow hydrology
- Machine learning and forecasting
- Surface and overland flow
- Aridity and the Budyko framework
- Extreme events and drought
- Water resources and management
